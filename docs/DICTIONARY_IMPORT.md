# Dictionary import and editable study cards

Open **Hanzi Mastery: import, edit and create study cards** from RemNote's command menu. The **Import** page accepts Traditional words separated by spaces or new lines. **Import words** looks up readings and English meanings and creates editable translation cards in one step. There is no fixed word-count limit. Select **Review before importing** to preview/edit first; **Manual entry** and **Settings** have their own tabs. Automatic imports use the first MOE reading with matching English definitions; words without a matching definition are skipped with an explanation.

## Native list bullets

A vocabulary list is an ordinary RemNote parent bullet. Use **New list name → Create list bullet** to add one beneath the Hanzi Mastery document, or focus any ordinary bullet before opening the workbench to select it, including nested/external bullets. The list selector shows the default collection, its ordinary child bullets and the current external selection. Focusing a vocabulary entry or its review card selects the vocabulary's actual parent.

The native outline is **List → character or word → study cards**. Word headings contain the Traditional characters only and are sorted using Traditional Chinese collation, then pinyin for alternate readings. Other list bullets retain their relative order after vocabulary headings. No list Powerup or separate membership database is required. Existing flat vocabulary remains under the default Hanzi Mastery collection. Rename or move list bullets directly in RemNote; **Refresh lists from RemNote** reloads their titles and the current vocabulary's actual parent. New skill cards sit beneath the vocabulary entry. Moving that word bullet in RemNote carries its nested cards with it.

To relocate existing vocabulary, select its destination and use **Move vocabulary and cards to selected list**. This moves the vocabulary and linked writing/recall Rems together, confirms their parents, and preserves native schedules, practice directions and plugin history. If interrupted, retry to finish the remaining moves. The plugin rejects a destination beneath the vocabulary or its linked cards. Native manual movement of a vocabulary entry alone is recognized on refresh; use the move action to bring its cards along.

## Large lists and resuming

Lookup requests remain sequential, with progress updates and event-loop yields between 25-word batches. Preview pages show 25 words at a time; import processes selected entries across every page. **Stop lookup** cancels the current request. Successful results and edited choices remain in the open workbench; looking up again requests only unfinished/failed words. That preview cache is session-only.

**Stop import after current entry** finishes the current vocabulary and its translation card(s) before stopping. Running import again skips completed rows and retries pending/failed ones. Persistent retry links also reuse completed notes after reopening the workbench and looking up the words again. Large lists naturally take longer and remain subject to dictionary/RemNote availability; the earlier 50-word cap was a conservative UI limit, not a RemNote restriction.

## Sources

| Field | Source |
| --- | --- |
| Reading and Chinese source definitions | Taiwan Ministry of Education Revised Dictionary data through the documented Moedict `/uni/` API |
| English study suggestions and explicit Simplified forms | Unmodified local CC-CEDICT snapshot published by MDBG, release 2026-10-17T16:45:37Z, 125,297 entries |
| Editable study wording | Learner-selected/edited text, stored separately from original source records |
| Multiple-choice ambiguity filtering | Bundled pinyin-pro polyphonic data plus vocabulary readings; not the source of imported answers |

The [MOE public-data page](https://language.moe.gov.tw/001/Upload/Files/site_content/M0001/respub/index.html) licenses its dictionaries under CC BY-ND 3.0 TW. This integration uses the [Moedict project's documented API](https://github.com/g0v/moedict-webkit#api), not an MOE website scraper or an official government API. Its response does not report a source edition, so the plugin records that limitation and the retrieval time. The Revised Dictionary includes historical readings; the [MOE FAQ](https://dict.revised.moe.edu.tw/qa.jsp?la=0&powerMode=0) recommends its Concise/Elementary dictionaries for teaching. Imported readings are source-backed suggestions for review, not a claim of current Taiwan curriculum compliance.

[CC-CEDICT](https://www.mdbg.net/chinese/dictionary?page=cedict) provides community-maintained Chinese-English entries under CC BY-SA 4.0. English definitions are not MOE-authored. The original compressed source, copyright/release header, license link and SHA256 are distributed with the plugin. The package validator verifies its exact bytes. No dictionary readings or meanings are generated by a language model.

## Preview and import

Each word shows the supported MOE readings. Automatic import selects the first MOE reading with a matching English definition. In the optional preview, multiple readings require a deliberate choice; no ambiguous row is included by default. English suggestions are matched to the selected reading, including explicit CC-CEDICT Taiwan-pronunciation annotations. When no English entry matches, enter an English study meaning or skip the item; a different reading's definitions are not silently substituted.

Use semicolons to separate study meanings. The **Original dictionary entry** panel shows the unmodified source definitions and attribution. Checking a row and selecting **Import selected entries and translation cards** creates a vocabulary heading and one **bidirectional translation Rem** below it. RemNote schedules its forward (meaning → characters) and backward (characters → meaning) cards independently. Existing separate translation Rems are reused without merging, deleting or enabling disabled cards. Unknown/unsupported entries show an error and can be added manually. No automatic Traditional conversion or word segmentation is performed.

Imports reserve retry links before drafting notes. Retrying a partial failure or importing the same headword/reading again in the same list reuses the same vocabulary and card Rems. The actual Rem parent determines membership, so native moves are respected even if an old retry index points elsewhere. The same word in separate lists gets separate entries/cards. Previously edited vocabulary is retained on reimport; importing is not a silent dictionary refresh. Different readings have separate entries. Existing manually authored entries are not automatically merged with dictionary imports.

## Translation reviews

Native parent/question context is hidden only in Hanzi Mastery study reviews so the character heading cannot reveal the answer; native rating controls remain available. Both directions require a typed first answer before comparing it with the reference. Select **My answer is correct** or **Needs practice** after comparison. Equivalent wording and valid synonymous Chinese expressions require human judgment, so the saved result is explicitly self-assessed. Revealing the native answer before comparison fails independent recall; revealing it after intentional comparison does not invalidate the assessment. First answers remain fixed, and each direction has its own native schedule and saved result history.

## Editing

Select **Edit imported …**, or focus a Hanzi Vocabulary entry and reopen the workbench. Edit the Traditional/Simplified forms, pinyin or English study meanings, then select **Save vocabulary and update study cards**. Linked study-card metadata, native questions and answers are updated in place, without changing practice direction or native repetition history. Existing linked cards are grouped beneath their vocabulary heading, preserving their IDs. Original dictionary provenance is retained. Separately authored writing-card prompts are not rewritten by this study-card editor.

Changes are validated before writes. Saves use metadata read-back confirmation. A partial linked-card update reports that vocabulary was saved and asks you to retry to finish; the editor keeps the draft. Changed translation prompts or target readings use separate plugin result keys, preserving previous results rather than deleting them. RemNote retains its scheduling/rating controls. Start another entry with **Add more words**.

## Network and acceptance

Lookup sends only the submitted words, one request at a time, to `https://www.moedict.tw/uni/…`. English lookup reads the local compressed snapshot. Requests time out after 15 seconds; per-word failures are shown. Reviews of imported cards do not require a fresh dictionary query. New online lookups require connectivity, and Moedict availability can change. Source definitions may include markup as plain text; they are never rendered as executable HTML.

Live Chromium CORS probes on 2026-10-21 returned exact entries and source definitions for 學習 (xué xí / xué xi), 行 (four readings) and 垃圾 (lè sè). End-to-end import/edit/reimport tests use the real compressed CC-CEDICT snapshot and compiled RemNote SDK, with synthetic MOE responses and simulated host RPC. Live Windows checks on 2026-10-22 confirmed automatic import of 水, 書, 十 and 行, native character ordering and bidirectional translation Rems. Physical iOS remains unverified.
