The application queries this local snapshot for both readings and English glosses. Imports retain the original source definitions separately from editable study wording and generate a matching-word MDBG link. No live MOE request is required for new imports. Existing entries that contain MOE provenance retain their original records and licences; this default change does not rewrite them. Audio has independent source/reading matching and licensing; see the adjacent audio attribution in the package.
