The application queries this local snapshot for English glosses; it does not present these as government-authored definitions. Readings and Chinese definitions are separately queried from the documented Moedict API, which mirrors Taiwan Ministry of Education Revised Dictionary data under CC BY-ND 3.0 TW. API responses are not included in this package. Source entries remain separate from editable learner wording. No MOE website scraping, machine-generated definitions or synthesized dictionary readings are used.

MOE source and license: https://language.moe.gov.tw/001/Upload/Files/site_content/M0001/respub/index.html
Moedict API documentation: https://github.com/g0v/moedict-webkit#api
